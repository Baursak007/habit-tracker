# Трекер привычек 📱

Нативное Android приложение для отслеживания привычек, написанное на Flutter.

## ✨ Возможности

- ✅ Добавление, редактирование и удаление привычек
- 🎯 Категории: Здоровье, Спорт, Образование, Работа, Хобби, Общение
- 📅 Ежедневные и еженедельные цели
- 🔥 Серии выполнения (streak)
- 📊 Статистика: графики за 7 дней, рейтинг, круговая диаграмма
- 🎨 Тёмная и светлая тема
- 🗓️ Мини-календарь выполнения (4 недели)
- 📤 Экспорт данных в CSV
- 💾 Локальное хранение (SQLite, без интернета)
- 🔍 Поиск и фильтрация по категориям

## 📥 Установка APK

1. Перейди в [Releases](https://github.com/Baursak007/habit-tracker/releases)
2. Скачай последний `HabitTracker-vX.apk`
3. На Android: **Настройки → Безопасность → Разрешить установку из неизвестных источников**
4. Открой скачанный файл

## 🛠️ Технологии

- **Flutter 3.24** + Dart 3
- **SQLite** (sqflite) — локальная база данных
- **Provider** — управление состоянием
- **FL Chart** — графики
- **Material Design 3**
- **Google Fonts** (Nunito)
- **GitHub Actions** — автоматическая сборка и релиз

## 🧪 Тесты

```bash
flutter test
```

## 🔄 CI/CD

При каждом push в `main`:
1. Запускаются тесты
2. Собирается APK
3. Создаётся GitHub Release со скачиваемым APK
